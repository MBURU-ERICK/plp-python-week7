# Week 7 Assignment: My Notes & The Report Builder

- `my_notes.py` — Writes three notes, appends a fourth, displays them, and counts the lines.
- `my_notes.txt` — The four notes generated by `my_notes.py`.
- `report_builder.py` — Reads learner scores from CSV, calculates results, and writes a report; handles a missing CSV safely.
- `hubs.csv` — Input data containing five learners, their hubs, and their scores.
- `report.txt` — Generated learner report showing totals, passes, failures, and average score.

If `"a"` were changed to `"w"` in Question 1, opening the file to add the fourth note would erase the first three notes. The file would then contain only the fourth note, and the line count would be 1.

## Run

From the repository directory:

```bash
python3 my_notes.py
python3 report_builder.py
```

## Test missing-file handling

```bash
mv hubs.csv hubs_backup.csv
python3 report_builder.py
mv hubs_backup.csv hubs.csv
python3 report_builder.py
```

The program prints `hubs.csv not found` when the CSV is absent and avoids dividing by zero. The last command regenerates the expected report.
